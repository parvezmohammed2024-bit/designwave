# Product photography

Each product's photo lives here, named by its slug (see `lib/products.ts`):

- business-standard.webp
- business-diecut.webp
- popup-card.webp
- stickers.webp
- thankyou-cards.webp
- eid-envelope.webp
- eid-wish-set.webp
- wedding-welcome.webp
- wedding-gift-note.webp
- scratch-card.webp
- coupon-card.webp
- combos.webp

To swap in new photography: replace the file (keep the name), done — no
code change. Recommended: WebP, portrait 5:7-ish (e.g. 1000×1400), shot
close-up so paper texture and edges are visible, consistent lighting
across the set. Until a file exists, the site shows a branded SVG
placeholder face automatically.
